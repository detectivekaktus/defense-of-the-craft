# Defense of the Craft
Defense of the Craft (DOTC) is a survival-oriented combat enhancement Fabric mod for 1.21.1 which adds Dota 2 artifacts and mechanics to Minecraft. The core features of the mod are:
* **Stats system** - strength, agility and intelligence
* **Pseudo-random procs** - evasion, bash, crit, bonus damage
* **New effects** - disarm, stun, break, armor reduction
* **50+ new items** - food, swords, axes and pickaxes
* **New radiant and dire ores** in the overworld and nether dimensions
* **Dota interface sounds** for screenshots, menus and commands

The mod is translated to *English, Russian, Ukrainian, and Spanish*.

## Dependencies
* [Fabric API](https://modrinth.com/mod/fabric-api)
* [YetAnotherConfigLib (YACL)](https://modrinth.com/mod/yacl)
* [ModMenu](https://modrinth.com/mod/modmenu)
